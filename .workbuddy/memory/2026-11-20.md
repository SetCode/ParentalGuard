## ParentalGuard · 版本更新检测 + Release 发布流程（commit d9dc20b）

- 新增 `app/src/main/java/com/tensun/parentalguard/update/UpdateChecker.kt`：
  - `VersionCompare` 只比较数字段，忽略 `v` 前缀与 `-beta` 后缀，段数 ≤4，单段 ≤9 位防溢出。
  - `UpdateResult` 五态：`Available` / `Latest` / `NoRelease`(404) / `NetworkError` / `FormatError`。
  - `HttpURLConnection` 直连 `api.github.com/repos/SetCode/ParentalGuard/releases/latest`，6s/8s 超时，必须带 User-Agent。
  - `checkAsync` 后台线程 + 主线程回调；`UpdatePrefs` 记录上次检查时间做 12 小时节流。
- `MainActivity` 增「版本与更新」卡片：`renderVersionInfo` / `maybeAutoUpdateCheck` / `runUpdateCheck` / `renderUpdateResult` / `showUpdateDialog` / `openUrl`；自动检查挂在密码门之后，避免提示框压住验证框。
- 版本号收敛：新增 `version.properties`（versionName=1.0.1，versionCode=10001），`app/build.gradle` 读取并允许 `-PversionName` / `-PversionCode` 覆盖；versionCode 规则 `主*10000+次*100+修订`。
- 测试：`app/src/test/.../VersionCompareTest.kt` 6 组用例；`app/build.gradle` 仅加 `testImplementation 'junit:junit:4.13.2'`，运行期仍零第三方依赖。
- 发布：`.github/workflows/release.yml`（tag `v*` 触发，Secrets `KEYSTORE_BASE64`/`KEYSTORE_PROPERTIES_BASE64` 注入签名，`gh release create/upload` 幂等）、`.github/workflows/ci.yml`（master/PR 跑单测 + assembleDebug）。
- `tools/release.sh`：写版本号 → 单测 → assembleRelease → apksigner 验签 → aapt2 核对包内 versionName/versionCode → dist/ + sha256 → `--push`（打 tag 推 CI）或 `--upload`（本地产物直接发 Release）。
- 文档：`docs/RELEASE.md`（版本规则、Secrets 生成、验证命令、五类判定表）+ README 新增第九节、更新交付树。
