# 儿童设备管控（ParentalGuard）

面向家长的 Android 设备管控应用，兼容手机与平板。以**完整可编译的 Android 工程**形式交付，包含配置界面、设备端限制逻辑、规则持久化、状态提示与运行时权限处理。

**提示面向儿童设计**：拦截和锁定都用大图标、鲜艳颜色、超大数字和**随应用内置的中文真人语音**说明原因，不依赖孩子识字，也不需要设备预装语音引擎、不需要联网；家长可分别设置是否出声、是否朗读、是否弹图形。

## 二、功能与规则语义

| 规则 | 行为 | 解除条件 |
| --- | --- | --- |
| 每日设备总使用时长 | 当日所有应用前台时长累计达到上限后，全设备锁定 | 次日 00:00 自动解除 |
| 单次连续使用 + 强制休息 | 连续使用达到上限后进入强制休息，休息期间限制设备使用 | 休息倒计时结束后，若其他规则允许则自动恢复 |
| 应用白名单 | 白名单外应用**一打开就立即送回桌面**，同时用大图标与中文语音说明原因 | 切换到允许的应用即解除；系统桌面与管控应用自动放行 |
| 单应用每日累计时长 | 可为多个应用分别设置上限，超额后该应用当天禁止使用 | 次日 00:00 自动恢复 |

**规则叠加**：所有启用的规则同时判定，命中项全部收集并展示；执行时按「更严格」择优：
1. 作用域更大者优先：全设备锁定 > 仅当前应用限制；
2. 同作用域下自动解除时间更晚者优先（例如「次日零点」胜过「切换应用即解除」）。

**配置操作**：每条规则可独立启用/禁用；每日时长、连续/休息时长可修改；白名单应用可增删；单应用限额可新增、修改时长、单独启用/禁用、删除；另有管控总开关与四项儿童提示开关。修改后服务下一秒心跳即生效，无需重启。

**即时拦截**：无障碍服务在窗口切换事件到达的瞬间调用 `BlockJudge` 判定白名单 / 单应用限额，命中即 `performGlobalAction(GLOBAL_ACTION_HOME)` 返回桌面并弹出提示，不必等待 1 秒心跳；心跳仍作为兜底，且与即时拦截共用去重键，保证一次拦截只提示一次。全设备级限制（每日总量、休息）由全屏遮罩统一处理，不会误报「应用不允许」。

## 三、计数与生命周期

- **计费单位**：「前台片段」。应用切换 / 灭屏 / 每 5 秒结算一次，写入 SharedPreferences；服务被杀或重启最多丢失 5 秒。
- **日期切换**：`DATE_CHANGED`、`TIME_SET`、`TIMEZONE_CHANGED` 广播 + 每次心跳双重检查；跨天清零每日总用量、各应用用量、连续用量与提醒标记，**保留配置**；未结束的强制休息继续保留，避免通过跨天绕过。
- **设备重启**：`BOOT_COMPLETED` / `MY_PACKAGE_REPLACED` 拉起常驻服务；同一天的每日计数**不清零**，并用系统「使用情况访问」数据对账取较大值，防止重启刷时长；持续中的休息期继续生效。
- **应用切换**：关闭旧片段并把时长归属到旧应用，再开启新片段；单应用限额按包名独立累计。
- **锁定 / 休息 / 灭屏期间不计时**；熄屏超过 5 分钟视为新的连续使用段。
- **降级前台检测**：无障碍服务未开启时，用 `UsageEvents` 最近一次前台切换事件兜底识别当前应用。

## 四、界面与提示（儿童不识字也能理解）

- 主界面每秒刷新：状态（可用 / 已锁定）、**全部锁定原因**、今日剩余时长与进度条、本次连续剩余时长与进度条、**强制休息倒计时**、当前前台应用、各单应用今日剩余时长。
- **全屏限制遮罩（每日总量 / 强制休息）**：112dp 大图标（蓝色月亮 / 紫色时钟）、34sp 儿童短句（「该休息啦」「今天用完啦」）、46sp 超大倒计时与进度条。规则标题、全部命中原因、今日已用时长等文字缩小为家长辅助说明。白名单 / 单应用超额这类「仅当前应用」限制不弹全屏遮罩，只用短时图形卡片，避免盖住桌面。
- **拦截图形卡片**：打开白名单外 / 超额应用时先返回桌面，再弹出约 2.4 秒的鲜艳色卡片（大图标 + 34sp 短句，如「不能玩哦」「今天玩够啦」）。窗口不可触摸、不抢焦点，不阻挡孩子操作桌面。
- **内置中文语音播报**：8 条真人中文短句 mp3 随 APK 打包在 `res/raw`，由 `MediaPlayer` 直接播放，例如「这个应用不能玩哦，已经帮你回到桌面啦」「该休息啦，让眼睛歇一歇，休息好了再玩」「休息好啦，可以再玩一会儿」。**不依赖系统 TextToSpeech 引擎、不依赖中文语音包、不联网、不需要额外权限**，装好即可朗读；2.5 秒去重避免重复播报，媒体音量低于 60% 时临时调高、播完自动还原。
- 常驻通知：显示剩余时长 / 休息倒计时 / 锁定原因，点击回到主界面（家长向，保留文字）。
- **声音提醒**：到点前 1 分钟预警、进入锁定、进入休息、休息结束、拦截应用时振动；人声语音开启时播报内置语音，关闭时改播系统通知音，两者不叠加。
- **家长密码**：默认 `1234`，可在「修改家长密码」中改为 4~8 位数字或留空关闭；冷启动及从锁定遮罩进入家长设置时均需验证。

### 儿童提示方式设置（主界面底部）

| 开关 | 默认 | 关闭后的行为 |
| --- | --- | --- |
| ① 有声提示（总开关） | 开 | 提示音、振动、语音全部静音；图形提示与全部限制照常执行 |
| ② 人声语音（内置中文朗读） | 开 | 只播提示音 + 振动，不朗读原因 |
| ③ 拦截应用时出声提醒 | 开 | 拦截仍立即返回桌面并弹图形卡片，只是不发声；锁定 / 休息提醒不受影响 |
| ④ 弹出图形提示 | 开 | 不弹短时图形卡片；全屏锁定遮罩始终显示 |

界面另提供「试听提示」「媒体音量设置」按钮，并常驻显示「内置中文语音：已就绪」与当前媒体音量（如 `媒体音量：3 / 15（偏低，播报时会自动临时调高）`）。② ③ 在 ① 关闭时自动置灰。若试听仍听不见，多为媒体音量过低或勿扰模式，点「媒体音量设置」调高即可。

> **重要**：四个开关只影响「提示」，不影响限制执行。自动返回桌面、全设备锁定、时长计数在任何设置下都照常工作。

## 五、权限（首次使用必须全部开启）

主界面「运行所需权限」区域会实时显示每项状态并提供跳转按钮：

| 权限 | 用途 | 授予路径 |
| --- | --- | --- |
| 使用情况访问 | 统计前台时长、重启对账 | 设置 → 应用 → 特殊权限 → 使用情况访问 |
| 无障碍服务 | 识别前台应用、执行返回桌面、**窗口切换即时拦截** | 设置 → 无障碍 → 儿童设备管控 · 应用监测 |
| 悬浮窗 | 显示全屏锁定遮罩**与拦截图形卡片** | 设置 → 显示在其他应用上层 |
| 通知（Android 13+） | 常驻服务通知 | 运行时弹窗授权 |
| 忽略电池优化 | 避免后台服务被系统冻结 | 设置 → 电池 → 电池优化 |

缺少悬浮窗权限时，图形卡片降级为系统 Toast（文字），语音播报仍可用；服务仍会周期性把设备送回桌面兜底执行限制，但无法展示遮罩，请务必开启。

**中文语音不需要任何权限或系统组件**：语音是打包在 APK 内的 mp3，不是设备文字转语音（TTS）引擎，因此设备没有 TTS 引擎、没有中文语音包、处于离线状态都不影响朗读。仅受系统媒体音量 / 勿扰模式影响，界面会显示当前媒体音量便于排查。

## 六、构建与安装

### 方式 A：Android Studio（推荐）
1. 使用 Android Studio（Giraffe 及以上）打开 `ParentalGuard` 目录；
2. 确保已安装 SDK Platform 34 与 Build-Tools 34.0.0，JDK 17；
3. `Build → Build Bundle(s) / APK(s) → Build APK(s)`，或点击运行直接安装到设备。

### 方式 B：命令行
```bash
# 需要 JDK 17、Android SDK（platforms;android-34、build-tools;34.0.0）
export JAVA_HOME=/path/to/jdk-17
export ANDROID_HOME=/path/to/android-sdk
./gradlew assembleDebug        # 调试版
./gradlew assembleRelease     # 已签名发布版
# 产物：app/build/outputs/apk/{debug,release}/...
adb install -r ParentalGuard-v1.0.0.apk
```

### 重新生成内置语音（可选）

`app/src/main/res/raw/voice_*.mp3` 是 8 条预生成的中文真人语音（约 196 KB），已随工程交付，**构建时不需要联网、不需要任何生成工具**。若要修改朗读文案或音色，可执行：

```bash
pip install edge-tts
python tools/generate_voice.py
```

脚本使用 `zh-CN-XiaoxiaoNeural`（语速 -8%、音调 +8Hz）合成，输出的文案与 `KidPrompt.cueOf()` 一一对应；改完文案后重新编译 APK 即可。

- 换机器后请删除 `local.properties`（若存在），让 Android Studio 自动生成，或改用 `ANDROID_HOME` 环境变量。
- 工程根目录的 `release.jks` + `keystore.properties` 是**演示用发布签名密钥**（口令 `parentalguard2026`，别名 `parentalguard`），`assembleRelease` 会自动读取并签名。正式分发时请替换为自有密钥并妥善保管，不要提交到公开仓库。
- 交付目录中的 `ParentalGuard-v1.0.0.apk` 已通过 `apksigner verify`（v2 签名）。
- 国内网络若 Gradle 发行包下载缓慢，可把 `gradle/wrapper/gradle-wrapper.properties` 的 `distributionUrl` 改为 `https://mirrors.huaweicloud.com/gradle/gradle-8.2-bin.zip`。

## 七、验证建议（可用 Emulator 或真机）

| 场景 | 操作 | 预期 |
| --- | --- | --- |
| 每日总量 | 设为 2 分钟，使用任意应用 | 2 分钟后全屏锁定，紫色时钟 + 次日零点倒计时 |
| 强制休息 | 连续 1 分钟 / 休息 1 分钟 | 到点出现蓝色月亮 + 倒计时，结束后绿色「可以玩啦」卡片并自动解锁 |
| 白名单拦截 | 只勾选一个应用，然后打开另一个 | **瞬间返回桌面**，弹出红色禁止卡片并朗读「这个应用不能玩哦…」 |
| 单应用限额 | 对某应用设 1 分钟 | 该应用累计 1 分钟后被拦截，橙色「今天玩够啦」提示，其他应用仍可用 |
| 冲突 | 同时触发每日总量与应用限额 | 全设备锁定优先；界面同时列出两条原因 |
| 静音模式 | 关闭「① 有声提示」后打开白名单外应用 | 仍返回桌面并显示图形卡片，但完全无声 |
| 只关拦截声音 | 关闭「③ 拦截应用时出声提醒」后打开白名单外应用 | 仍返回桌面并弹图形卡片，无提示音与语音；到点锁定提醒仍有声 |
| 试听 | 点「试听提示」 | 弹出蓝色卡片，振动并朗读内置人声「这是提示音测试…」，不叠加提示音 |
| 无语音引擎设备 | 在系统设置中停用 / 卸载 TTS 引擎后点「试听提示」 | 仍能正常朗读中文语音（语音为 APK 内置音频，与系统 TTS 无关） |
| 重启 | 用掉部分时长后重启 | 当日已用时长保留，继续按剩余时间执行 |
| 跨天 | 修改系统日期到次日 | 每日计数清零，设备恢复可用 |
| 禁用规则 | 关闭某条规则开关 | 下一秒该限制失效，其他规则继续生效 |

## 八、已知限制

- 本应用使用「无障碍服务 + 悬浮窗 + 使用情况访问」实现**普通应用级**管控，未使用 Device Owner / Device Policy Manager（后者需要设备管理器 provisioning，普通安装无法获得）。因此：手势导航的系统级操作、通知栏快捷设置、部分厂商分屏/小窗无法 100% 拦截；儿童仍可能通过系统设置强行关闭无障碍服务，建议配合系统「屏幕固定」或设备自带家长控制使用。
- 部分国产 ROM 会主动冻结后台服务，需加入电池优化白名单 / 自启动白名单 / 后台锁定。
- 内置语音走媒体音量 `STREAM_MUSIC`：媒体音量过低、静音或勿扰模式下可能听不见。应用会在播报时临时把媒体音量提到 60%、播完还原；若设备禁止应用调整音量，请家长点「媒体音量设置」手动调高。图形卡片、振动与限制执行在任何情况下都有效。
- 内置语音是固定 8 条短句（真人录音式合成音频），不能朗读任意自定义文本；新增提示场景需同步修改 `KidPrompt.cueOf()` 与 `tools/generate_voice.py` 并重编 APK。
- 图形卡片与锁定遮罩依赖悬浮窗权限；未授权时降级为系统 Toast + 语音播报 + 周期性返回桌面。
- `QUERY_ALL_PACKAGES` 用于列举应用，上架 Google Play 需提交权限声明；侧载与国内应用商店不受影响。
- targetSdk 固定为 33，以规避 Android 14 对前台服务 `specialUse` 类型的审核要求；在 Android 14+ 设备上仍可正常安装运行。
- 关闭人声语音后的提示音使用系统默认通知音，静音 / 勿扰模式下可能被系统抑制。
